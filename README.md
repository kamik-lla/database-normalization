## Нормализация таблиц, структура, индексы

### Задание:
Создайте исходную таблицу на языке SQL.
Заполните таблицу данными, используя INSERT INTO.
Произведите приведение исходной таблицы в нормальную форму путем создания новых таблиц (CREATE TABLE) и/или изменения исходной таблицы (ALTER TABLE). По возможности, страрайтесь сохранить данные в начальной ненормализованной таблице.
Объясните в нескольких предложениях суть ваших изменений.
